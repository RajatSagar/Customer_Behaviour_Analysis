# 📊 Customer Shopping Behavior Analysis

## 📌 Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, sales trends, and business insights.

The project follows a complete end-to-end Data Analytics workflow, starting from data loading and exploratory data analysis in Python, followed by data cleaning, SQL-based analysis, interactive visualization in Power BI, report preparation, and presentation creation using Gamma.

The objective is to transform raw customer data into meaningful insights that can support data-driven business decisions.

---

## 🎯 Project Objectives

- Analyze customer purchasing behavior.
- Understand sales and purchasing patterns.
- Identify important customer segments.
- Clean and prepare raw data for analysis.
- Perform exploratory data analysis using Python.
- Write SQL queries to extract business insights.
- Build an interactive Power BI dashboard.
- Create a detailed analytical report.
- Present the findings through a professional PPT created using Gamma.

---

## 📂 Dataset

The project uses a Customer Shopping Behavior dataset containing information related to customer purchases and shopping patterns.

### Example Dataset Attributes

- Customer ID
- Age
- Gender
- Category
- Item Purchased
- Purchase Amount
- Location
- Season
- Review Rating
- Subscription Status
- Discount Applied
- Payment Method
- Shipping Type
- Previous Purchases

The dataset is first loaded into Python and analyzed before being cleaned and prepared for further analysis.
